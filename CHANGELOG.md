# Changelog

## 24.0.0 — Unified Day Instrument

- Consolidated Pacefold into one current public experience.
- Added an analog and digital Clock with a live second hand.
- Added timezone-aware Day Unfold progress, a moving workday sun and scheduled markers.
- Added a current rhythm strip for location-aware Islamic prayer times or editable personal moments.
- Added a visible Daybook fold with daily totals and recent notes.
- Refined hydration, preparation timer, rest, meal, eye-reset and movement actions.
- Unified Notes, Worklog, Now, Settings and Sound under one visual system.
- Rebuilt the public website, PWA manifest, offline shell and release markers.
- Removed the former Ma product layer from the public app.
- Replaced historical Ma/V19/V20 production gates with a Pacefold 24 current-product browser audit.
- Simplified deployment to one production workflow with direct manual dispatch support.

## Earlier releases

Earlier release history remains available in the repository’s Git history and merged pull requests. Pacefold 24 intentionally stops presenting historical visual layers as parts of the current product.
