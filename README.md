# Pacefold 25

Pacefold is a quiet, clock-first workday rhythm app. `canonical/` is the complete production source for Pacefold 25.

Pacefold 25 no longer rebuilds production by layering historical releases. Git history preserves V15–V24; the current branch deploys V25 directly. Stable browser-storage schema keys remain intentionally compatible so existing notes, preferences, backups, and activity history survive the cleanup.

Current release: **25.0.0 canonical-r1**.
